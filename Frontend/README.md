# TaskFlow Frontend

Frontend sử dụng React và Vite, giao diện CSS thuần để giữ dự án đơn giản.

## Chạy dự án

1. Chạy backend tại `http://localhost:5284`.
2. Trong thư mục `Frontend`, cài package và chạy:

```powershell
npm install
npm run dev
```

3. Mở `http://localhost:5173` trên trình duyệt.

Địa chỉ backend được khai báo bằng biến `API_URL` ở đầu file `src/App.jsx`.
